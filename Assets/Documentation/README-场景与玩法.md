# 掼蛋 · Unity/PICO XR

主场景：`Assets/Scenes/GuandanTomb.unity`

## 在 Scene 中修改模型

- `01_Environment · 可自由替换模型`：墓穴建筑、牌桌、座位、灯具、夺宝轨道与装饰。其下对象均为保存到 Scene 的普通 GameObject，可直接移动、删除、缩放或替换网格。
- `02_Gameplay · 玩法与锚点`：规则控制器、玩家手牌、桌面出牌、夺宝和世界 UI 的定位点。可以移动定位点来配合新模型，但不要删除；场景加载时会复用已保存的按钮和文字，不会重复生成。
- `03_XR Rig · PICO与桌面共用`：地面级 XR 原点、头显相机、左右控制器和射线。
- `04_Props · 鲜花与西红柿`：社交道具占位模型。

如果确实需要从头重建占位场景，使用 Unity 菜单 `掼蛋 > 一键创建或重建可编辑墓穴场景`。该操作会覆盖主 Scene；日常换模型不应执行它。

## 操作

- 桌面：鼠标左键点牌/按钮，中键拖动环绕，方向键环绕和缩放，`Enter` 出牌，`Space` 不出，`F1` 最小合法提示，`R` 重置视角。
- PICO：左右控制器可见射线，扳机选择牌和世界按钮，并提供短促震动反馈。

## 已迁移玩法

- 双副牌、四人两队、级牌与红桃级牌“逢人配”。
- 单张、对子、三张、三带二、顺子、连对、钢板、四至八张炸弹、同花顺、四王炸。
- 四家轮转、接牌/不出、牌权重置、四名次、双上提前结束。
- 进贡、还贡、两张大王抗贡。
- 双上 3 格、头游三游 2 格、头游末游 1 格。
- 双方十格夺宝，稳当与激进路线；激进结果为翻倍 10%、+1 格 15%、正常 55%、-1 格 12%、倒退一格 8%。
- 三名 AI、最小可压牌提示、鲜花和西红柿交互入口。

## 构建

- `掼蛋 > 配置 PICO Android 项目`
- `掼蛋 > 验证项目`
- `掼蛋 > 构建 > macOS 桌面测试包`
- `掼蛋 > 构建 > PICO Android APK`

PICO 配置目标为官方 Unity、PICO XR 6.0.0、Android ARM64、IL2CPP、Activity、Input System-only、PXR Loader、OpenGLES3/Vulkan 和 Multiview；最低 Android API 为 29。Unity Android 工具链不支持中文工程路径；若从菜单构建 APK，请将同一工程临时复制到仅含 ASCII 的路径后构建，再将 APK 放回本项目 `Builds/Android`。
